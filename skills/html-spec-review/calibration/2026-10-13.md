# Calibration run — 2026-10-13

Method and results of running `html-spec-review` against 10 randomly chosen recent whatwg/html PRs. Kept so later rule changes can be checked against the same baseline.

Per foolip's suggestion on [whatwg/spec-ai#2](https://github.com/whatwg/spec-ai/pull/2#pullrequestreview-5503532419): run the skill on randomly chosen recent PRs, including merged ones, to find common false positives and rules "we're not enforcing as it is". Sample: `random.seed(2026)` over PRs #12800–#13060 → 6 merged, 4 open. One subagent per PR applied every rule in `html-style-guide.md` + SKILL to the added/changed lines only, then compared against the actual human review comments.

## 2. What was over-firing (and what changed)

| Pattern | Evidence | Change |
|---|---|---|
